# Практики 9–11 — ветеринарная клиника «Лапа рядом»

Учебный сайт ветеринарной клиники. Посетитель может ознакомиться с услугами, прочитать описание приёма и заполнить форму записи. Используются HTML, Bootstrap 5, собственный CSS и JavaScript. Формы демонстрационные: данные не отправляются и не сохраняются.

## Страницы

- `index.html` — главная, преимущества клиники, популярные услуги и модальное окно быстрой записи.
- `catalog.html` — каталог услуг с карточками, стоимостью, длительностью и FAQ.
- `product.html` — подробное описание первичного приёма и таблица стоимости.
- `order.html` — форма записи с данными владельца и питомца.
- `contacts.html` — контактная информация и часы работы.

## Bootstrap-компоненты

Используются `container`, `row`, адаптивные `col-*`, `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `accordion`, `form-control`, `form-select`, `input-group` и `form-check`. Собственные правила находятся в `css/custom.css`, подключённом после Bootstrap. Интерактивные компоненты работают через Bootstrap JS Bundle, подключённый через CDN.

## Самостоятельные решения

- Тематика заменена на ветеринарную клинику: сайт услуг вместо магазина.
- Добавлена отдельная страница контактов.
- В каталоге указаны ориентировочные стоимость и длительность услуг.
- Форма собирает вид питомца, кличку, услугу и желаемую дату; поля проверяются браузером.
- Кнопка записи из карточки передаёт выбранную услугу в модальное окно.
- Добавлены собственные иллюстрации, адаптивная сетка и стили с учётом настройки уменьшения анимации.

## Запуск

Откройте `index.html` в браузере. Для Bootstrap CDN нужен интернет. Перейдите в каталог или нажмите «Записать питомца», чтобы посмотреть демонстрационную форму.

### Постановка КР3

КР3 — самостоятельный новый проект по теме адаптивной вёрстки и доступности многостраничного HTML/CSS-сайта. Он не является продолжением КР1 или КР2. Для него потребуется отдельный репозиторий, адаптация страниц для телефона, планшета и компьютера, проверка доступности с клавиатуры, подписей полей и изображений, а также настоящий отчёт Lighthouse.
