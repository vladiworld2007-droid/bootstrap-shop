# Контрольная работа №2 — ТехноЛавка на Bootstrap

Учебный интернет-магазин техники для контрольной работы №2. Практическая работа 9 посвящена Bootstrap-сетке: `container`, `row`, `col-*`, адаптивным брейкпоинтам и отступам `g-*`.

## Практическая работа 9

Главная страница использует Bootstrap 5 через CDN и собственный файл `css/custom.css`. Добавлены шапка, навигация, hero-блок, преимущества, популярные товары и подвал. Сетка перестраивается на небольших и широких экранах.

## Запуск

Откройте `index.html` в браузере. Для загрузки Bootstrap нужен интернет.
