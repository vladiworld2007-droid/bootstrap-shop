# Практики 9–11 — ветеринарная клиника «Лапа рядом»

Учебный сайт ветеринарной клиники. Посетитель может ознакомиться с услугами, прочитать описание приёма и заполнить форму записи. Используются HTML, Bootstrap 5, собственный CSS и JavaScript. Формы демонстрационные: данные не отправляются в клинику. Учебные записи, отзывы и карточка питомца сохраняются только в localStorage текущего браузера.

## Страницы

- `index.html` — главная, преимущества клиники, популярные услуги и модальное окно быстрой записи.
- `catalog.html` — каталог услуг с карточками, стоимостью, длительностью и FAQ.
- `product.html` — подробное описание первичного приёма и таблица стоимости.
- `order.html` — форма записи с данными владельца и питомца.
- `contacts.html` — контактная информация, часы работы и карта.

## Пять интерактивных возможностей

1. **Отзывы** — на главной странице можно поставить оценку и оставить комментарий; записи сохраняются локально.
2. **Интерактивная запись** — на странице записи выбираются услуга, дата и время (временные слоты демонстрационные, реальная занятость не проверяется); результат сохраняется только в браузере.
3. **Карточка питомца** — на главной странице можно сохранить кличку, вид, возраст, вес и сведения о вакцинациях.
4. **Калькулятор услуг** — в каталоге можно отметить несколько услуг и увидеть ориентировочную сумму.
5. **Чат с консультантом** — на каждой странице доступно всплывающее окно с автоматическими ответами на частые вопросы. Это **не чат с реальным сотрудником**.

**Ограничения:** сервер и общая база данных отсутствуют. Отзывы и записи не видны другим посетителям и сотрудникам клиники; для настоящей онлайн-записи и живого чата понадобится backend/внешний сервис. Не используйте демонстрационную карточку для конфиденциальных медицинских данных.

## Bootstrap-компоненты

Используются `container`, `row`, адаптивные `col-*`, `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `accordion`, `form-control`, `form-select`, `input-group` и `form-check`. Собственные правила находятся в `css/custom.css`, подключённом после Bootstrap. Интерактивные компоненты работают через Bootstrap JS Bundle, подключённый через CDN.

## Самостоятельные решения

- Тематика заменена на ветеринарную клинику: сайт услуг вместо магазина.
- Добавлена отдельная страница контактов.
- В каталоге указаны ориентировочные стоимость и длительность услуг.
- Форма собирает вид питомца, кличку, услугу и желаемую дату; поля проверяются браузером.
- Кнопка записи из карточки передаёт выбранную услугу в модальное окно.
- Добавлены собственные иллюстрации, адаптивная сетка и стили с учётом настройки уменьшения анимации.

## Запуск

Откройте `index.html` в браузере. Для Bootstrap CDN нужен интернет. Перейдите в каталог или нажмите «Записать питомца», чтобы посмотреть демонстрационную форму.

## Практическое занятие 11 — итоговая проверка КР2

Практическое занятие №11 фиксирует готовность проекта КР2 к сдаче. В проекте клиники подготовлены:

- главная страница, каталог услуг, описание услуги и форма записи;
- общая Bootstrap-навигация на страницах;
- сетка Bootstrap, карточки, кнопки, значки, сообщения и модальное окно;
- Bootstrap-форма с `form-control`, `form-select`, `input-group` и `form-check`;

Формы демонстрационные и не отправляют данные в клинику. Для показа преподавателю нужно открыть страницы в браузере, показать навигацию, карточки, модальное окно, форму и accordion.

### Постановка КР3

КР3 — самостоятельный новый проект по теме адаптивной вёрстки и доступности многостраничного HTML/CSS-сайта. Он не является продолжением КР1 или КР2. Для него потребуется отдельный репозиторий, адаптация страниц для телефона, планшета и компьютера, проверка доступности с клавиатуры, подписей полей и изображений, а также настоящий отчёт Lighthouse.
